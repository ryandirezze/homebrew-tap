# Homebrew Tap

Homebrew casks for [NovaCAD](https://github.com/ryandirezze/NovaCAD-Mac) and other ryandirezze Mac apps.

## NovaCAD

```sh
brew install --cask ryandirezze/tap/novacad
```

The cask is bumped automatically from the latest [NovaCAD-Mac release](https://github.com/ryandirezze/NovaCAD-Mac/releases/latest) by [`.github/workflows/auto-bump.yml`](.github/workflows/auto-bump.yml) — daily, or on demand from the Actions tab.
